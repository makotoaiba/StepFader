# Step Fader

トラックに挿して、オートメーション用のフェーダーとして使う VST3 エフェクトです。
ボタンを押すだけで「+3 dB」「-6 dB」のように段階的に動かせるので、オートメーションをポンポン書けます。

## 操作

| 操作 | 内容 |
|---|---|
| ＋6 / ＋3 / ＋1 / －1 / －3 / －6 | 今の値から相対的に動かす。連打すると積み重なる（グライド中でも行き先に加算） |
| 0 dB | 0 dB に戻す |
| -∞ / 戻す | -∞ まで下げる。もう一度押すと下げる前の値に戻す |
| A / B / C | クリックで呼び出し。右クリック（または Shift+クリック）で今の値を記憶 |
| フェーダー | ドラッグ、ホイールで 0.5 dB（Shift で 0.1 dB）、ダブルクリックで 0 dB |
| トリム | フェーダーに足す固定の補正。オートメーションとは別に使う |

キーボード（プラグイン画面をクリックしてから）：
↑↓ ±1 dB、Shift+↑↓ ±3 dB、PageUp/PageDown ±6 dB、0 で 0 dB、M で -∞/戻す、1〜3 でメモリー呼び出し

## グライド

ボタンで値が変わるまでの時間です。即時 / 30 ms / 100 ms / 300 ms / 1 s / 1拍 / 2拍 / 1小節 から選べます。
オートメーションには、この時間の傾きとして書き込まれます。

## Cubase でのオートメーション記録

1. トラックのオートメーションを **Touch** または **Latch** にして W（書き込み）を ON にする
2. 再生しながらボタンを押す → 「Fader」パラメーターに書き込まれる
3. 書き終わったら R（読み取り）だけにして再生

R だけのとき（読み取りモード）にボタンを押しても、すぐにオートメーションの値に戻ります。

## インストール（テスト用）

Actions の成果物 zip を展開し、`install_for_test.bat` を実行してから DAW でプラグインを再スキャンしてください。
